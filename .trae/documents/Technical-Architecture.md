# 象棋棋谱展示工具 技术架构文档

```

│                  Frontend                    │
```

## 2. 技术栈
- **框架**：React@18 + Vite
- **样式**：Tailwind CSS
- **截图**：html2canvas
- **图标**：Lucide React
- **构建**：vite

## 3. 组件结构

| 组件 | 职责 |
|------|------|
| App | 根组件，状态管理 |
| ChessBoard | 棋盘渲染，棋子展示 |
| ControlBar | 播放控制按钮 |
| MoveList | 步数侧边栏 |
| ScreenshotButton | 截图功能 |

```typescript
interface GameState {
```

## 5. DhtmlXQ解析规则

### 5.1 初始棋盘(binit)
- 89位字符串，每位代表一个棋子位置
- 9=将/帅, 1=车, 2=马, 3=象/相, 4=士/仕, 5=炮, 6=卒/兵, 0=空

### 5.2 步法列表(movelist)
- 连续数字字符串，每4位一组表示一步
- 前2位：起点位置编码
- 后2位：终点位置编码
