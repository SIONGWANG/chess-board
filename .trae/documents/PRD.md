# 象棋棋谱展示工具 PRD

## 1. 产品概述
- 一款用于展示DhtmlXQ格式象棋棋谱的工具，支持棋谱播放、浏览和截图
- 解决用户需要可视化查看象棋对局、复盘分析的需求
- 目标用户：象棋爱好者、棋谱研究者

## 2. 核心功能

### 2.1 功能模块
1. **棋盘展示**：渲染标准中国象棋棋盘，包含棋子位置和移动动画
2. **棋谱解析**：解析DhtmlXQ格式的棋谱数据，还原每一步走法
3. **播放控制**：
   - 开局：回到棋谱开始
   - 退一步：回退一步
   - 前进一步：前进一步
   - 终局：跳到棋谱结束
4. **步数侧边栏**：显示当前步数和所有步数的列表，高亮当前步
5. **棋盘截图**：截取纯棋盘图片（不含UI），用于分享或保存

## 3. 核心流程

### 3.1 棋谱加载流程
```
用户粘贴DhtmlXQ代码 → 解析棋谱数据 → 初始化棋盘 → 等待用户操作
```

### 3.2 棋谱播放流程
```
用户点击播放控制 → 更新棋子位置 → 更新侧边栏高亮 → 等待下一步操作
```

### 3.3 截图流程
```
用户点击截图按钮 → 仅捕获棋盘DOM → 转换为图片 → 自动下载
```

## 4. 用户界面设计

### 4.1 设计风格
- **色彩**：深色木质纹理背景（#2D1810），棋盘采用传统木色（#DEB887）
- **按钮**：圆角按钮，悬停有阴影效果
- **字体**：思源黑体/Noto Sans SC，标题使用楷体风格
- **布局**：左侧棋盘，右侧步数列表，底部控制栏

### 4.2 页面设计
| 区域 | 模块 | UI元素 |
|------|------|--------|
| 主区域 | 棋盘 | 10x9交叉线棋盘，棋子SVG |
| 右侧 | 步数列表 | 带高亮的垂直列表 |
| 底部 | 控制栏 | 开局/退/前/终局按钮 + 截图按钮 |

### 4.3 响应式设计
- 桌面端优先，棋盘最小宽度400px
- 移动端棋盘自适应屏幕宽度

## 5. 技术方案

### 5.1 技术栈
- **前端**：React@18 + Vite
- **样式**：Tailwind CSS
- **截图**：html2canvas
- **图标**：Lucide React

### 5.3 棋谱解析规则
- 解析DhtmlXQ_binit生成初始棋盘
- 解析DhtmlXQ_movelist生成步法列表
- 使用标准象棋走法规则验证和展示
